# FACTORIZACION LU
Repositorio que contiene código de ejecución del método numérico ***Factorización LU*** para una matriz de 3 x 3.

## Dependencias
Este repositorio utiliza las tecnologías y librerías
```
- python >= 3.13
- numpy >= 2.5.0
- scipy >= 1.17.0
```
Las librerías para utilizarlo están contenidas en el fichero:
```
- requirements.txt
```

## Uso
Para la prueba de este repositorio se debe instalar python `(python => 3.13.0 recomendada)`.

Se recomienda utilizar un entorno virtual .venv para su ejecución
```
Creación de un Entorno Virtual
python -m venv .venv 

Activación del Entorno Virtual (Windows Powershell)
.venv/Scripts/Activate.ps1 

Actualización de instalador de paquetes PIP
python -m pip install --upgrade pip

Instalar librerias
$ pip install -r requirements.txt
```

*Se realiza este proyecto con propósitos educacionales. Se recomienda discreción para su uso.*
